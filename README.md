# NDTA 631 Group Project: Data Analysis & Visualization

## Project Overview
This project investigates how the informal economy affects income inequality in South Africa, using two World Bank datasets. It covers all assignment deliverables:
- Data Preparation
- Numerical Analysis
- Visualization
- Database Integration
- Data Analysis
- Report & Demo

## Folder Structure
- `notebooks/` – Jupyter notebooks for each deliverable
- `data/` – Raw and processed data files
- `dashboard.py` – Streamlit dashboard for interactive demo
- `requirements.txt` – Python dependencies

## Setup Instructions
1. Clone this repository.
2. Install dependencies:
	```
	pip install -r requirements.txt
	```
3. Run the dashboard:
	```
    python streamlit -m run dashboard.py
    or
    streamlit run dashboard.py
	```
4. Explore the notebooks in the `notebooks/` folder for detailed code and analysis.

## Dependencies
See `requirements.txt` for all required Python packages.

## Dashboard Walkthrough
The dashboard covers all deliverables. Use the sidebar to navigate:
- **Project Overview:** Introduction and assignment context.
- **Data Preparation:** Shows raw data samples, missing values, and summary statistics.
- **Numerical Analysis:** Key statistics, NumPy operations, and correlation metrics.
- **Visualization:** Interactive bar, histogram, box, scatter, and line plots.
- **Database Integration:** Demonstrates database creation, querying, updating, and deletion.
- **Data Analysis:** Outlier removal, conditional formatting, ratio analysis, and findings.
- **Report & Demo:** Access the final report and codebase.

## How to Use
1. Launch the dashboard and use the sidebar to explore each section.
2. Adjust filters and widgets to interact with the data.
3. Review the notebooks for code, methodology, and deeper analysis.
4. Use the provided report for submission and reference.
